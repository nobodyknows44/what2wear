# План квартиры

Чертёж собран по рукописным обмерам с фотографии `IMG_2445` (эскиз с замерами).

| Файл | Назначение |
|---|---|
| `apartment-plan.drawio` | редактируемый чертёж — открывается в [app.diagrams.net](https://app.diagrams.net) или в плагине draw.io для VS Code |
| `apartment-plan.svg` / `.png` | превью для просмотра без draw.io |
| `src/` | скрипты, которыми чертёж собран (геометрия + генерация через `cli-anything-drawio`) |

Формат листа A3 (1169 × 1654), масштаб 1:100, все размеры в метрах по внутренним граням стен.

## Что требует уточнения

1. **Назначение помещений.** На эскизе подписей нет — названия («Комната 1», «Помещение 2» …)
   и расположение дверей приняты условно.
2. **Скошенный угол прихожей у входа** (`0,515 / 0,502 / 0,647 / 0,629`, толщина `0,11`)
   вычерчен прямым — на эскизе это ломаная под углом.
3. **Ширина коридора** (1,653 м) получена вычислением: от южной стены Комнаты 1 до северной
   стены Помещения 3. Прямого замера ширины коридора на эскизе нет.
4. **Размеры без однозначной привязки:** `0,155`, `0,172`, `0,2`, `0,1`, `0,735`, `0,05`, `0,15`.
5. **Расхождения в замерах:**
   - Помещение 2: восточная стена по замерам `0,676 + 0,613 + 1,051 = 2,340`,
     по замыканию контура — `2,101` (разница 24 см).
   - Комната 4: уступ северной стены по замыканию `0,722`, на эскизе подписан `1,3`.
   - Комната 4: `0,55 + 0,66 + 1,085 = 2,295` против ширины `2,669` (остаток 0,374 показан как пилястра).

## Как пересобрать

```bash
pip install cli-anything-drawio
python3 src/build_drawio.py      # генерирует build.sh
bash build.sh                    # собирает apartment-plan.drawio
python3 src/render_drawio.py apartment-plan.drawio apartment-plan.svg
```
