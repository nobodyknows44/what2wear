# План квартиры

Чертёж собран по рукописным обмерам с фотографии `IMG_2445` (эскиз с замерами).

| Файл | Назначение |
|---|---|
| `apartment-plan.drawio` | редактируемый чертёж — открывается в [app.diagrams.net](https://app.diagrams.net) или в плагине draw.io для VS Code |
| `apartment-plan.svg` / `.png` | превью для просмотра без draw.io |
| `src/` | скрипты, которыми чертёж собран (геометрия + генерация через `cli-anything-drawio`) |

Чертёж выполнен **1:1 в метрах**, размеры сняты по внутренним граням стен.

## Как включить метры в draw.io

draw.io умеет показывать метры, но пересчитывает их жёстко: `PIXELS_PER_MM = 3.937`,
то есть **1 м = 3937 единиц**. Поэтому чертёж и сделан 1:1 — тогда метры настоящие.

1. Откройте файл и один раз включите **View → Units → Meters** (Вид → Единицы → Метры).
   Настройка глобальная (хранится в браузере), в самом файле её нет.
2. После этого панель **Arrange**, линейка (View → Ruler) и подсказки при перетаскивании
   показывают метры: ширина стены 2.959 читается как 2,959 м. Шаг ввода — 1 мм.
3. Сетка выставлена на **0,05 м** (`gridSize=196.85`), привязка идёт по 5 см.

### Размерные линии считают себя сами

Каждая размерная линия — отдельная фигура с подписью `%width-m%` / `%height-m%`.
draw.io подставляет туда её собственный размер, поэтому **при правке число пересчитывается
автоматически**: потянули конец линии — подпись обновилась. Никаких «отставших» цифр.

Работает это только если у фигуры значение — объект с `placeholders="1"`:

```xml
<object label="%width-m%" placeholders="1" id="…">
  <mxCell style="…" vertex="1" parent="1">…</mxCell>
</object>
```

Обычная строка-подпись не подставляется (`Graph.isReplacePlaceholders`), поэтому после
сборки через CLI запускается `src/postprocess.py` — он оборачивает размерные ячейки.

Серым под размером подписан замер с эскиза — **только там, где он расходится с чертежом**.

## Что требует уточнения

1. **Назначение помещений.** На эскизе подписей нет — названия («Комната 1», «Помещение 2» …)
   и расположение дверей приняты условно.
2. **Скошенный угол прихожей у входа** (`0,515 / 0,502 / 0,647 / 0,629`, толщина `0,11`)
   вычерчен прямым — на эскизе это ломаная под углом.
3. **Ширина коридора** (1,653 м) получена вычислением: от южной стены Комнаты 1 до северной
   стены Помещения 3. Прямого замера ширины коридора на эскизе нет.
4. **Размеры без однозначной привязки:** `0,155`, `0,172`, `0,2`, `0,1`, `0,735`, `0,05`, `0,15`.
5. **Расхождения в замерах:**
   - Помещение 2: восточная стена по замерам `0,676 + 0,613 + 1,051 = 2,340`,
     по замыканию контура — `2,101` (разница 24 см).
   - Комната 4: уступ северной стены по замыканию `0,722`, на эскизе подписан `1,3`.
   - Комната 4: `0,55 + 0,66 + 1,085 = 2,295` против ширины `2,669` (остаток 0,374 показан как пилястра).

## Как пересобрать

```bash
pip install cli-anything-drawio
python3 src/build_drawio.py                     # генерирует build.sh
bash build.sh                                   # собирает apartment-plan.drawio
python3 src/postprocess.py apartment-plan.drawio 196.85   # живые размеры + сетка
python3 src/render_drawio.py apartment-plan.drawio apartment-plan.svg
```

Геометрия задана в `src/plan.py` в метрах — правки замеров делаются там, чертёж
пересобирается целиком.
